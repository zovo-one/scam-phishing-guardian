# Scam & Phishing Guardian

Spots scam and fake-login sites and shows the exact reason, on your device. Warns, never blocks. No browsing history leaves it.

Free and open source. If it saves you time, you can support the work on [GitHub Sponsors](https://github.com/sponsors/theluckystrike), [PayPal](https://paypal.me/najzzz) or [Buy Me a Coffee](https://buymeacoffee.com/michaellip).

## Install

- From the Chrome Web Store: [Scam & Phishing Guardian](https://chromewebstore.google.com/detail/halkfmfdfgilipmckkmapcgjffcoifli). Version 1.0.5.
- From this repository: open `chrome://extensions`, turn on Developer mode, click Load unpacked, and select this folder. No build step is needed.

## Permissions

`storage`, `activeTab`, `scripting`, `alarms`, `declarativeNetRequest`, `offscreen` plus host access for `http://*/*`, `https://*/*`, `https://raw.githubusercontent.com/*`, `https://urlhaus.abuse.ch/*`, `https://crt.sh/*`, `https://zgubxqomnbmxgbdhvwja.supabase.co/*`.
